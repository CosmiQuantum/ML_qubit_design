# Coupler NCap Capacitance Matrix

This experiment predicts coupler `NCap` capacitance-matrix behavior.

- `ml_00_*` through `ml_03_*` are the main analysis, training, evaluation, and tuner-analysis notebooks.
- `ml_10_*` through `ml_22_*` hold surrogate and defined-loss variants.
- `validation_00_AnsysQ3D_simulations.ipynb` contains Q3D validation work.
- `plots/`, `plot_outputs/`, `sweep_outputs/`, and `sweeps/` contain generated artifacts and sweep results.
- `metadata/` holds saved names/config artifacts; `results/` groups training, prediction, and validation CSV outputs.
