# Coupler NCap Capacitance Matrix

This experiment predicts coupler `NCap` capacitance matrix behavior.

1. `ml_00_*` through `ml_03_*` are the main analysis, training, evaluation, and tuner analysis notebooks.
2. `ml_10_*` through `ml_22_*` hold surrogate and defined loss variants.
3. `validation_00_EM_simulations.ipynb` contains Q3D validation work.
4. `plots`, `plot_outputs`, `sweep_outputs`, and `sweeps` contain generated artifacts and sweep results.
5. `metadata` holds saved names and config artifacts.
6. `results` groups training, prediction, and validation CSV outputs.
